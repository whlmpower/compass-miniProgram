设计理念

我们不做「你适合大厂 / 国企」的标签式结论。职业罗盘以心理学框架（大五人格、施恩职业锚、施瓦茨价值观、依恋类型、风险容忍度、家庭锚点）为镜，用苏格拉底式提问，帮你把模糊的纠结拆开，看见自己真正在乎的东西。

技术说明

对话由大模型驱动，后端调用国产 OpenAI 兼容 API（DeepSeek / 通义 / GLM），按你输入的上下文实时生成问题与分析。诊断完成后生成一份结构化的《职业自我认知报告》（含伦理声明与危机求助热线）。

隐私协议

职业罗盘隐私协议（摘要）

1. 我们采集什么。仅采集你在本产品中主动输入的对话内容（职业困惑、个人经历、价值观描述等），用于本次职业自我认知诊断，驱动 AI 生成报告。

2. 广告相关数据采集。本产品含广告（模拟 / 激励视频）。广告 SDK 可能采集设备信息、广告曝光与点击等行为数据，用于广告投放与计费。我们无法控制第三方广告 SDK 的独立数据处理，相关处理遵循其隐私政策。

3. 数据存储与删除。诊断（报告生成）完成后，你的对话原文与报告文件在服务器端保留 24 小时，期间你可重复查看 / 下载；超过 24 小时系统自动删除，不作长期留存。我们不会把你的诊断内容用于训练或对外提供。

4. 交易与统计。解锁 / 使用统计仅含次数、时间等聚合数据，不含任何个人诊断内容。

5. 你的权利。你可随时停止使用；24 小时后数据自动清除。如对数据处理有疑问，可通过产品内联系方式反馈。

本协议为产品内摘要，完整条款以最新版本为准。AI 生成内容不构成职业或心理咨询建议。
